The controlled reference day uses direct source `Appear` calls at entry and every20seconds. The native public API retains original day1 arrivals every14seconds; its browser bot uses a different fixture. Source cash18 and native cash24 are separate successful scenarios, not an identical-input score comparison.

The experimental static suffix grouping for symbol193 failed the composition pixel check and is rejected/default-disabled. The rejected final-stage tile compositor is verification-only under `src/verification/`, excluded from the native release. Intermediate allocation or frame-rate measurements do not turn either experiment into an accepted optimization. The 7/7 GPU filter result compares the native GPU kernel with its CPU reference; it does not validate these experiments or all historical source pixels.

For remaining open comparisons, [decisions.md](decisions.md) defines the evidence needed. Recorded browser scenarios do not imply unrun listening, real-device multitouch, all-browser coverage, remote score acceptance or final performance acceptance. Performance status remains in its dedicated plan.
